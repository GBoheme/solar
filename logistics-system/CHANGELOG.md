# سجل التغييرات — Changelog

## 1.1.0 — نمط الاستخدام الشخصي (2026-07)

### إزالة المصادقة (الطلب الأساسي)
- حذف صفحة تسجيل الدخول وواجهات الجلسات بالكامل — التطبيق يفتح مباشرة على لوحة التحكم.
- حذف: middleware المصادقة، `api/auth/*`، شاشة المستخدمين، `api/users/*`، زر الخروج، منطق كلمات المرور، مكتبتي `jose` و`bcryptjs`.
- هوية داخلية موحدة «Ghaith Boheme» (قابلة للتغيير من الإعدادات) تسجل بها كل الحركات.
- بقي كاملاً: سجل التدقيق، الطوابع الزمنية، تاريخ النسخ المولدة، تتبع أعدّه/دققه/أصدره.

### جديد
- **صفحة الإعدادات والصيانة**: اسم التطبيق، اسم المالك، تذييل التقارير والمستندات، المنتج الافتراضي.
- **النسخ الاحتياطي**: ZIP كامل (قاعدة البيانات + المرفقات + الكتب المولدة + القوالب + `backup-info.json`).
- **إعادة التعيين الآمنة** بنمطين (مسح تشغيلي / تصفير كامل) مع عبارة تأكيد حرفية إلزامية وحذف ذري داخل معاملة قاعدة بيانات.
- **بصمة التجاوز الدقيقة**: كل تجاوز تحذير يرتبط ببصمة (نوع الخطأ + الحقل + مرجع الكيان مثل رقم الاستمارة) فلا يخفي أخطاء أخرى مستقبلاً.
- **معاينة استيراد Excel قبل الحفظ**: تقرير كامل (إجمالي/صالح/مرفوض/مكرر داخل الملف/مكرر مع الجدول) + تنزيل الصفوف المرفوضة CSV + الكتابة الذرية.
- **رقم الإصدار الظاهر** في الشريط الجانبي والإعدادات، وملف CHANGELOG.
- فهارس قاعدة بيانات على الحقول الساخنة (حالة المعاملة، رقم الاستمارة، رقم السيارة).
- تذييل الكتب المولدة (Word/PDF) يقرأ من الإعدادات ويتضمن هوية المُعد.

## 1.0.0 — الإصدار الأول
