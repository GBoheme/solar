■ المتطلب الوحيد قبل البدء:
  تثبيت Node.js نسخة 20 أو أحدث من:  https://nodejs.org
  (اختر النسخة LTS، والتثبيت الافتراضي كافٍ)

──────────────────────────────────────────────────────────────

■ التشغيل السريع (الطريقة الأسهل):

  • على Windows:
      انقر نقراً مزدوجاً على الملف:  START-WINDOWS.bat

  • على macOS أو Linux:
      افتح Terminal في هذا المجلد ونفّذ:
        chmod +x START-MAC-LINUX.sh
        ./START-MAC-LINUX.sh

  السكربت يقوم تلقائياً بـ: تثبيت الحزم، إنشاء قاعدة البيانات،
  زرع البيانات التجريبية، ثم تشغيل التطبيق.

──────────────────────────────────────────────────────────────

■ التشغيل اليدوي (إن أردت):

    npm install
    npm run setup
    npm run dev

──────────────────────────────────────────────────────────────

■ بعد التشغيل:

  افتح المتصفح على العنوان:   http://localhost:3100

  التطبيق للاستخدام الشخصي — يفتح مباشرة على لوحة التحكم
  بلا تسجيل دخول. الهوية واسم المالك يُعدّلان من شاشة
  «الإعدادات والصيانة»، ومنها أيضاً النسخ الاحتياطي
  وإعادة تعيين البيانات.

──────────────────────────────────────────────────────────────

■ ملاحظة حول توليد PDF:

  توليد ملف PDF النهائي يحتاج متصفح Chromium/Chrome.
  إن ظهرت رسالة "لم يتم العثور على Chromium"، ثبّت المتصفح
  وأضف مساره في ملف .env بالسطر:
    CHROMIUM_PATH="مسار/المتصفح"
  (توليد Word لا يحتاج ذلك ويعمل مباشرة)
